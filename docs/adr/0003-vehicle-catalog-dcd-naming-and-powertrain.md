# ADR 0003：车型目录以懂车帝命名为准，动力类型由用户选择

日期：2026-09-01
状态：已接受（停售条目圈选已完成，排除规则与最终结论见"决定"第 5 条）

## 背景

老目录精选条目（191 条，带"（燃油版）"这类动力后缀，人工指定保养模板）与懂车帝抓取条目并存，
选择器里出现"帝豪（燃油版）+ 帝豪"这类疑似重复。最初的想法是合并出一份"裸名目录"，
但分析懂车帝数据后发现：它的车系名自带品牌前缀（小米SU7）、品牌短名前缀（问界M9、银河L6）、
以及动力拆分（秦PLUS DM 与 秦PLUS EV 是两条不同车系）。任何"去前缀、合并同车系"的处理
都会制造出懂车帝里不存在的名字，与"重新抓取时以懂车帝原始命名对账"的既有约定冲突。

## 决定

1. **目录条目名以懂车帝原始车系名为准**：不合并、不去前缀、不去动力词。秦PLUS DM 和
   秦PLUS EV 是两条；"小米SU7""ZEEKR 001"原名保留。
2. **老目录精选条目（191 条）全部废弃**：目录以懂车帝数据为唯一来源。懂车帝覆盖
   不到的车型（科鲁泽、云朵、理想 L7 这类懂车帝按停售/下架处理的），通过选择器里的
   "自定义车型"手输入口兜底。`legacy_vehicles.json` 仅留档，不再参与目录生成。
3. **动力类型由用户在添加车辆时选择**：燃油 / 混动（油电混动）/ 插混（插电混动）/ 增程 / 纯电
   五选一。目录按车系名和品牌推断一个"推荐动力类型"仅作预选，用户可改。增程与插混共用
   同一套保养内容。
4. **默认保养模板按动力类型预置**（fuel / hybrid / plugIn / extended / ev 五组，增程组与
   插混组内容相同；思域专用的 civicFuel 精修模板删除，2026-09-01 起为思域单独恢复，
   见 ADR 0004），不再按"品牌+车型"逐条存放。
   `vehicle_default_maintenance_items` 表从约 1.8 万行缩成按动力类型约 50 行。
5. **停售车系进目录，未上市不进**：停售条目中带"（海外）/（进口）"标记的排除、
   纯英文名的排除（多为海外车）、4 条中文名但欧洲未入华的（现代 i20、现代 i10、
   沃尔沃 V70、起亚Ceed）排除；其余 30 条进。未上市（含预售）全是概念车与海外变体，不进。
6. **车辆表新增动力类型字段**（`cars.powertrainType`，数据库 schemaVersion 9）：已添加的老车
   与 v3 备份导入的车不回填推断，一律默认燃油；备份契约升 v4，兼容读 v3。
7. **动力类型添加后不可修改**（编辑车辆不提供入口）；它只影响添加时的默认保养项目和
   "恢复默认项目"，不改动已生成的项目。

## 后果

- 最初"车型名不带动力类型"的目标只对老目录条目成立；懂车帝名字里本来就带 DM/EV/PHEV
  的照原样带，用户选完车型仍单独选动力类型。
- 目录里会存在"同名不同动力"的相邻条目（懂车帝拆分使然），这是接受的状态，不是 bug。
- catalogId 仍按懂车帝原始车系名（品牌|车系名）算哈希，重新抓取后对账稳定。
- 目录规模 1675 条：在售 1645 + 停售 30（海外标记、纯英文名、欧洲未入华中文名条目已排除）。
- 2026-09-01 目录精简为每品牌最多 10 款热门车型（共 1223 条）；被裁的内置车型行由
  `_ensureVehicleModels` 幂等对账自动清理，`cars` 表存的是品牌/车型文本值，不受影响。
- 目录数据来源以 car_library 下品牌文件为准（index.json 的统计元数据可能滞后）。
- 老目录曾有的人工模板精度（civicFuel 等）不再保留；默认项目精度=动力类型粒度
  （思域例外见 ADR 0004）。

## 备选方案

- **合并懂车帝动力拆分、去品牌前缀，造出裸名目录**：选择器更"干净"，但目录里会出现懂车帝
  没有的合成名，重抓对账和"以懂车帝为准"的数据原则都被破坏，拒绝。
- **老目录补缺保留（撞懂车帝的删、真缺的仿风格命名保留）**：能救回十几款懂车帝下架的
  车型，但要长期维护"懂车帝 + 老目录"两套命名与归一化比对规则；产品选择纯懂车帝单一
  来源 + 自定义输入兜底，拒绝。
- **保留按品牌+车型的逐条默认模板（老目录模式）**：模板精度高，但这正是本次要解决的
  "带后缀条目与裸名条目并存"问题的根源，且 1600+ 抓取条目养不起人工模板，拒绝。
- **停售数据全进 / 未上市也进**：停售 117 条里 44 条带海外标记、39 条纯英文名多为海外车；
  未上市 2617 条几乎全是概念车，进来只添乱，拒绝（停售做了排除后进）。
