# ADR 0006：油价真源用 qiyoujiage 网页解析，示例数据源退役

日期：2026-09-01
状态：已接受

## 背景

加油预测上线时真接口未定，内置了示例假数据源（见 docs/adr/0001）。现已选定数据来源：`http://m.qiyoujiage.com`（汽油价格网移动版首页）。该站没有公开 JSON 接口，返回的是 HTML 页面，但结构稳定：一张表格给出全国 31 个省级行政区 × 4 个油品（92/95/98/0#）的每升价，页面另附一段"下次油价X月X日24时调整，目前预计上调/下调油价N元/吨(M元/升-P元/升)"的调价预告文字。

## 决定

1. 按 ADR 0001 的适配器约定，新增 `QiyouJiaFuelPriceSource` 实现 `FuelPriceSource`，替换注入；删除 `MockFuelPriceSource`（含省份清单迁移走，省份选择器不再依赖它）。
2. 解析用宽松规则（正则匹配表格行和预告句式），不依赖精确 DOM 层级；解析不到的字段宁缺毋错，不抛异常影响油价主体数据。预告的方向与金额锚定到"下次油价X月X日"命中句的窗口内（句号/换行标签截断），页面其他文章里的同款字样不参与解析。
3. 一次请求把全国 31 省价格全部缓存（换省不再发请求）；调价预告全国一份，随同缓存。
4. 调价预告的每升变动是区间（如 0.05~0.06 元/升）时取中值参与计算；方向（涨/跌）单独保留。
5. 预估下次油价 = 当前生效每升价（手填价优先）+ 变动中值；"调价后价格"列、预估块都基于它。
6. HTTP 用 `http` 包；明文 http 需要平台放行：iOS 在 Info.plist 为 `m.qiyoujiage.com` 加 ATS 例外域；Android 9+（API 28）默认拦截明文流量，用 network security config 只对该域放行（`android/app/src/main/res/xml/network_security_config.xml`，挂到主清单 `android:networkSecurityConfig`；注意启用后清单里的 `usesCleartextTraffic` 标志会被系统忽略）。
7. 拉取时机沿用 10 个自然日 + 手动刷新规则。

## 后果

- 解析对象是网页而非契约接口：站点改版会解析失败，表现为错误态 + 手动重试，不做自动回退假数据（避免用户按假价算钱）。
- 油价缓存结构从"单省"扩为"全国 + 预告"，仍是偏好临时数据，不进备份。
- 预告本身有时段性（调价日当天会更新成下一次预告），10 天刷新窗口内可能短暂显示过期预告，接受。

## 备选方案

- 只缓存当前省：改动最小，但换省要重新发请求，失败时新省份没价。
- 解析失败回退示例假价：界面看不出异常，误导计算，放弃。
- dart:io `HttpClient`：零依赖但代码啰嗦；`http` 是标准做法。
