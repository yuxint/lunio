# ADR 0027：OBD 连接生命周期 App 级化与提醒页快速连接

日期：2026-11-16
状态：已接受

## 背景

诊断连接编排（ADR 0020/0024）原来是页面级生命周期：进诊断页连接、
离页 dispose 断开。2026-11-16 拍板在提醒页英雄卡加「连接OBD」快速连
接按钮与油量水温信息卡（诊断开关转正后，提醒页需要不进诊断页就能连
上适配器的入口），页面级生命周期撑不住：提醒页与诊断页是两个路由栈
条目，两个 controller 各自建链会在共享 radio 单例上抢链路。

## 关键取舍

- **App 级共享 vs 提醒页独立 controller**：独立 controller 让离页即
  断的旧语义保留，但同一 radio 两个会话抢链路、两侧状态互不知晓；
  App 级共享一个连接，提醒页与诊断页同源渲染。拍板 App 级共享。
- **快速连接不落扫描**：现有直连失败自动开扫描 sheet。快速连接的语
  义是「连上一次那台」，弹扫描是另一个流程。拍板直连失败不落扫描，
  失败 toast 错误文案。
- **轮询清单作用域换防**：提醒页只需要油量/水温两条核心读数，诊断页
  要全量启用清单；连接期间常驻轮询（默认 30s/条）有耗电代价，拍板
  作用域换防：诊断页在栈顶 = 全量，退回提醒页 = 核心两条。
- **提醒页读数不回退持久化**：诊断页读数「实时优先、持久化回退」；
  快速连接信息卡是实时语义（连接中才有卡），拍板只显实时读数，无数
  据显「—」，另有手动刷新按钮与更新时间。
- **诊断开关关闭的收尾**：开关关闭时按钮/信息卡/入口行全部消失，留
  连接就是空转轮询。拍板关开关断开 App 级连接（动作层收尾）。

## 决定

1. DiagnosticsConnectionController 由 keepAlive provider 持有
   （obd_runtime.dart `obdConnectionControllerProvider`）：提醒页与
   诊断页共享同一连接；离诊断页不断开，进诊断页已连接则复用（start
   的 connected 守卫）。
2. 页面只挂/摘接缝与作用域：attachUi/detachUi（扫描 sheet 开/关）、
   setOdometerSyncHandler（ECU 里程静默同步回调）、setDiagnosticsScope
   （轮询清单作用域换防）；轮询快照 getter 按作用域取清单（background
   清单未推入时回退全量，防「已连接但轮询空表」）。
3. 快速连接 `connectRemembered`：只直连设备记忆（`lastObdDeviceId`），
   不落扫描；失败落「已断开」+ 错误文案，调用方 toast。按钮四态 =
   白（idle，与「更新里程」同款白胶囊）/黄（连接中/扫描中）/绿（已连
   接）/红（断开）；绿态点击 = 断开。
4. 提醒页只挂油量（012F）+ 水温（0167）两条核心检测点，频率取各检测
   点设置的刷新间隔；信息卡上刷新按钮 = requestImmediatePoll，更新
   时间取两条读数较新者（formatReadingTime 格式）。
5. ECU 里程静默同步回调只在诊断页作用域挂载：里程探针只在全量清单里
   轮询，同步行为与提示都只在诊断页期间发生。
6. 诊断开关关闭断开连接（setDiagnosticsEnabled 动作收尾）；读数落库
   写点直失效检测点 family（提醒页常驻订阅会缓存旧 lastValue）。
7. 「诊断连接编排」词条修订：连接生命周期由 App 级编排层持有，页面
   只负责触发与挂/摘接缝。

## 后果

- 诊断页「离开断开」的旧语义作废（widget 测试改写为「离页不断开」）；
  连接跨 tab 常驻轮询，耗电小幅增加（已接受）。
- 提醒页常驻订阅检测点 family，缓存陈旧问题由读数落库写点直失效收口。
- GLOSSARY「诊断连接编排」词条修订、新增「快速连接」词条；AGENTS、
  手册、iteration plan 同步。
- 真机待验：快速连接四态颜色在渐变底上的可读性、信息卡刷新手感、跨
  tab 常驻连接的耗电与稳定性、扫描 sheet 与快速连接的互斥时序。

## 修订节（2026-11-18）：两条拍板被后续轮次推翻

1. **提醒页背景轮询「核心两条」→ 三条**（ADR 0026 修订节）：里程表 01A6
   升内置后，背景轮询清单 = 油量/水温/里程三条，否则「只要连接就同步
   里程」不成立。
2. **提醒页信息卡时间行删除**（2026-11-18 拍板）：ObdReadingsCard 删
   「更新时间」行、字号对齐诊断页、水温按五段色染色、刷新按钮居中放大
   （ADR 0029 修订节二的同批 UI 修正）。

## 修订节二（2026-11-21）：扫描 sheet 不与其它 sheet 叠加

用户反馈：诊断页里打开调试终端的「会话日志」sheet 后，若此时连接失败，
controller 会按回落逻辑再弹「选择适配器」——两个 sheet 叠在一起。

1. **UI 接缝改为可拒绝**：`DiagnosticsConnectionUi.openScanSheet` 返回
   `bool`。页面实现里先判 `ModalRoute.of(context)?.isCurrent`——栈顶被
   别的路由占着（会话日志 sheet 走 `showGeneralDialog` 压了一条路由）
   就返回 false。
2. **controller 侧撤销而非等待**：`_openScanSheetNow` 收到 false 就停手：
   清 `_scanSheetOpen`、取消扫描订阅与扫描、**不启动扫描**，相位落到
   「有失败原因 → 已断开 + 原因；无原因 → 未连接」，两种都能靠状态条
   整卡点击重新发起。失败原因在开 sheet 前先存下，回滚时还回去（否则
   「连接失败 → 本该落扫描」这条链上用户看不到任何原因）。
3. 覆盖：controller 单测「页面开不了扫描 sheet：不叠加、撤销扫描」。
