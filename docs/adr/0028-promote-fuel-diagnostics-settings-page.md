# ADR 0028：加油预测与车辆诊断转正、设置页整合

日期：2026-11-16
状态：已接受

## 背景

开发者模式区块只剩手动日期一行时，区块名不副实；通知设置、主题模式、
功能开关散在「数据与工具」区里，我的页行数偏多。2026-11-16 拍板重组。

## 关键取舍

- **二级菜单形态**：通知设置已是 sheet、主题模式是行内即改，二级菜单
  若也用 sheet 会 sheet 叠 sheet。拍板二级菜单用独立页面（/settings，
  pushed 子页形态）；通知设置保留自己的 sheet，从设置页一行进入。
- **转正范围**：加油预测、车辆诊断两颗开关移出开发者区块，正常模式可
  见；诊断入口行（进入诊断页）移到我的页「清空数据」下方（诊断开关开
  才显示）。拍板保留开发者模式本体（footer 后缀、连点手势、手动日期
  仍挂开发者门控）。
- **连带清偏好**：关闭开发者模式原来连带清手动日期/加油预测/车辆诊断/
  ECU 里程自动同步四项；转正后连带清转正项是误伤正常功能。拍板连带只
  清手动日期。

## 决定

1. 我的页「数据与工具」区行序：设置、备份数据（行尾「备份」，原「导
   出」）、恢复数据、清空数据、进入诊断页（诊断开关开才显示）、手动
   日期（开发者模式专属）。费用统计行删除（记录页头部汇总行是既有入
   口）。
2. 设置页（/settings，pushed 子页）：「通用」分区 = 通知提醒行（弹现
   有通知设置 sheet）+ 主题模式三段；「功能开关」分区 = 加油预测 +
   车辆诊断。诊断开关关闭断开 App 级连接（ADR 0027 收尾）。
3. 加油预测、车辆诊断不再挂开发者门控：设置页「功能开关」分区直接可
   见，正常模式可用。`developerModeEnabled` 保留，用途收窄为：开发者
   区块（手动日期）显隐 + 版本 footer 后缀 + 连点手势。
4. 关闭开发者模式连带只清手动日期（saveManualDateOverride(null)）；
   加油预测、车辆诊断、obdOdometerAutoSync 不再受牵连。
5. `lastObdDeviceId` 偏好加 provider（lastObdDeviceIdProvider，watch
   偏好纪元；写点 bump 纪元）——提醒页按钮显隐的数据源。

## 后果

- 版本 footer 连点 5 次手势保留（开关开发者模式）；「我的页开发者区
  块只剩手动日期」。
- 费用统计行删除后入口只在记录页头部汇总行（整行可点）。
- GLOSSARY「诊断连接编排」修订、新增「快速连接」「设置页」词条；
  AGENTS、手册、iteration plan 同步。
- 真机待验：设置页视觉、我的页行序、连点手势与转正开关的互不干扰。
