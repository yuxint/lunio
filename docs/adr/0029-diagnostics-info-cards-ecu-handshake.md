# ADR 0029：诊断页信息卡化、ECU 握手判连与读数覆盖语义

日期：2026-11-17
状态：已接受

## 背景

诊断页三区布局（状态条 + 核心值卡 + 检测点行列表）经 2026-11-17 拷问
后重排：行列表的启停/管理入口与核心值卡重复；油量卡小字（可用/估算
总油量）与水温卡高度不齐；AT 序列成功即报「已连接」会误报（点火 OFF
总线休眠时 ECU 不响应，全量采集日志实证）；实时「无数据」会遮蔽持久
化最后值；用户提出观察冷启动→最佳工作状态与燃烧健康度的需求。

## 关键取舍

- **ECU 握手判连**：AT 序列成功只证明适配器在线（ELM 连上），点火
  OFF 时 ECU 睡着、发 PID 全 NO DATA——不算连接成功。拍板 AT 序列后
  追加一条 `0100`（OBD-II 法规强制支持位图查询，所有 OBD-II 车必响
  应）；有非错误响应行才算 connected；失败落「已断开」+「适配器已连
  上，但 ECU 无响应（检查点火开关）」，不自动重试（点火没开重试无意
  义）。
- **读数覆盖语义**：用户口径「有明确数据值才保存、才覆盖」。保存侧
  2026-11-15 已实现（只存 ObdValue）；显示侧本轮补齐：实时无数据不
  遮蔽持久化最后值（显示旧值+旧时间戳、不染色）；从未有过有效值才灰
  态「无数据」。提醒页信息卡语义不变（只信实时，ADR 0027）。
- **信息卡化**：行列表撤销，启用探针全员卡化——内置四张固定卡（油
  量/水温/电压/燃油修正），启用的自定义探针追加通用卡。启停唯一入口
  = 管理 sheet；管理入口迁「我的」页车辆卡「项目」后「检测点」按钮
  （Wrap 允许换行）。等高靠统一两段结构 + IntrinsicHeight。
- **燃油修正转正**：推翻 11-16「不加」拍板（理由已变：观察燃烧健康
  度）。0106/0107 两内置探针；卡显 LTFT 大字（染色基准）+ STFT 标题
  右端小字。**该卡不承担冷启动判别**（冷车开环修正冻结，判读需时序
  形态，30s/10s 采样做不到）；冷启动判读由水温卡色档承担。车主参考
  的论坛判读法（STFT 大幅负值）经核验为老进气道喷油车口径，1.5T 缸
  内直喷冷车加浓更轻。
- **染色口径**：水温 <70 灰（冷车，非警告）/ 70-85 黄 / 85-100 绿 /
  >100 红——用户最初提「>92 红」，本车热车怠速实测 95℃（0167 A 传
  感器）会常亮红，绿区上限定 100。电压（ATRV 电瓶口径）<11.5 红 /
  11.5~14.8 绿 / >14.8 红。燃油修正按 LTFT：±10 绿 / ±10~15 黄 /
  超 ±15 红。油量卡不染色。
- **油量估算展示全撤**：删「可用 X 升 · 估算总油量 Y 升」小字（用户
  拍板：信息卡不要小字、纯颜色驱动）。estimateFuel/FuelEstimate 随
  展示删除，012F 百分比是诊断侧唯一展示口径；总容积字段保留（加满
  预估档位列表用）。
- **默认轮询间隔 30→10s**：实测单条命令总线往返 ~120-200ms（一键检
  测 25 条全程约 3 秒），5 条探针单轮 ~0.75s、10s 间隔占空比 ~7.5%，
  对 500k CAN 与 ECU 远在安全区；暖机期水温 ~0.1-0.3℃/s，10s 粒度
  够；诊断页打开 ≤10s 必有新鲜值。逐点可调 5-3600 保留。
- **阈值不可读指标**：续航里程、变速箱油温、机油温度——标准 PID 本
  车全不支持（全量采集位图证实），本田私有 DID 未探索。进迭代计划
  想法池；读到之前阈值分析（如 CVT 60-85 绿）是纸上谈兵。

## 决定

1. 会话层 connect()：AT 序列 → `0100` 握手探测（超时或全错误关键词
   行 = ECU 无响应，Elm327EcuUnreachableException）→ 成功才置
   connected。controller 落「已断开」+ 上述文案。
2. readingFor 回退语义：实时 ObdValue 优先；实时 ObdNoData 回退持久
   化最后值；都无才灰态。
3. 诊断页信息卡网格（2×2 起）：油量 | 水温 / 电压 | 燃油修正 + 启
   用的自定义探针通用卡。卡=标题行（标题+右端时间戳）+ 大字值行。
   燃油修正卡大字=LTFT 染色、右端小字=STFT 实时值。
4. 内置种子 3→5 条（probe:stftBank1 / probe:ltftBank1），存量车
   bootstrap 自动补齐，默认启用。解析类型 fuelTrimPercent =(A−128)
   ×100/128，ObdValue.percent 语义放宽为「百分比数值（油量/燃油修
   正）」；ObdValue 新增 volts（ATRV 文本解析数值），celsius/volts
   不持久化→回退不染色；percent 持久化→燃油修正回退按旧值染。
5. 染色纯函数进 domain/rules/diagnostics_rules.dart（三个 tone 函
   数），页面只做 tone→颜色映射。
6. 管理 sheet 入口迁我的页车辆卡「检测点」按钮（锚定该车）；hero 卡
   删 subtitle（上路日期与「当前应用车辆」文案移除）；提醒页背景轮
   询不扩（仍油量+水温两条）。
7. 默认刷新间隔常量 30→10。
