### 1. 加油页在偏好纪元重算时被误重定向

- 位置：`lib/features/shell/app_shell.dart:115`
- 症状：用户停在加油页，修改省份/油品或保存手填油价后，页面跳回「我的」。
- 证据级别：已复现（widget 测试先红后绿）。
- 触发路径：`saveFuelProvince` / `saveFuelGrade` / `saveFuelManualPrice` bump `preferencesEpochProvider` → `fuelPredictionEnabledProvider` 重算进入 loading → AppShell 的 `maybeWhen(orElse: () => false)` 把 loading 当成「开关已关」→ `onDisabledFuel` 为真 → `context.go('/me')`。
- 复现：`flutter test test/widget/fuel_test.dart --plain-name 'fuel tab stays put when preference epoch bumps'` — 修复前 `Expected: exactly one matching candidate ... "当前油价" ... Found 0`；修复后通过。
- 根因：加载态与「开关关闭」被合并成同一个 `false`，而兜底重定向只应处理明确的关闭态。
- 修复：开关状态改为 `bool?`（loading → `null`），只有 `fuelEnabled == false` 才重定向；底部导航项只在 `true` 时出现。
- 回归：`flutter analyze` 无问题；`flutter test test/widget/fuel_test.dart` 21 用例全部通过。
- 提交：b2fd29e

### 2. 预登记车上路日期在未来时仍可新增保养/加油记录

- 位置：`lib/features/shell/records/record_form_controller.dart:375`、`lib/features/shell/fuel/fuel_record_form_controller.dart:170`
- 症状：车辆表单允许把上路日期设到今天之后（预登记车，最多提前一年）。此后打开「新增保养记录」或「记一笔加油」，表单默认日期是今天，日期选择器范围是「上路日期 ~ 今天」为空，没有任何可选日期；但直接填写并提交仍会保存一条日期早于上路日期的记录。
- 证据级别：已复现（两个控制器单测先红后绿）。
- 触发路径：车辆编辑/新增 → 上路日期选 `today + N` → 记录页/加油页新增 → 表单默认今天 → 填写金额/项目 → 提交。`SimpleDatePicker` 在 `firstDate > lastDate` 时全部日期禁用，但确定键仍返回初始值；两个控制器的 `submitPayload` / `_buildRecordDraft` 只校验金额、里程、项目，不校验日期范围。
- 复现：`flutter test test/features/record_form_controller_test.dart --plain-name '新增时车辆上路日期在未来'`、`flutter test test/features/fuel_record_form_controller_test.dart --plain-name '新增时车辆上路日期在未来'` — 修复前均返回非空载荷（`Expected: null / Actual: Instance of ...`）。
- 根因：日期下界只在日期选择器里表达，控制器提交路径没有兜底；预登记车的空日期区间没有单独的拦截分支。
- 修复：新增模式下若 `car.roadDate` 晚于生效今天，两个控制器都在提交入口直接报行内错误并返回 null（保养：「车辆上路日期在未来，暂不能添加保养记录」；加油：「车辆上路日期在未来，暂不能添加加油记录」）。编辑模式沿用原日期，不拦截，避免车辆后来改上路日期导致旧记录无法编辑。
- 回归：`flutter analyze` 无问题；定向 39 用例通过；全量 `flutter test` 972 用例全部通过。
- 提交：ad9b315
